Table view, refined

This builds on the table layout and the exercise strip from v2. Weights default to pounds. Six screens: logging, the keypad, adding a drop, swipe to delete, the hold menu, and the exercise list.

− PR badge removed from the table.
− "Mark as failure" and swapping mid-exercise removed.
↻ lbs by default; buttons are now + Drop · + Set.
+ Drop row with its own lbs and reps, under the set it belongs to.
+ "d" in Previous when you did a drop last time (e.g. 185 × 8 d).
+ List button pinned at the left of the strip opens all exercises.
