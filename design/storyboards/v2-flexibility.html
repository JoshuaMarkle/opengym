Built for a busy gym

The plan is a guide, not a script. You can do exercises in any order, add a drop set whenever you want, and swap Bench for Incline without breaking anything. Each problem below has 2–3 ways to solve it, then one screen that combines them.

− Rest timerRemoved. The bottom of the screen is now navigation.
− Exercise notesNo text under the exercise name.
+ Bottom navPrevious · All exercises · Next, always within thumb reach.
+ Flexible setsDo exercises in any order, add drop sets, swap variations.

Doing exercises out of order

The rack is taken, so you jump to whatever is free. The app shouldn't care what order you lift in. It should just make it fast to get to any exercise.
