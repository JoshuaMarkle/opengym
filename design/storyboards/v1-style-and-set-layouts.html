Set layout: three options

The same moment in each one: Bench Press, set 3 of 4, mid-rest after set 2.

OPTION A

Classic table

One row per set with Previous, kg, reps and a check box. This is the layout Strong and Hevy use, so it feels familiar.

  • Good: dense, and you can see every set and the previous numbers at once.
  • Good: easiest to build.
  • Weak: small tap targets on the inputs with sweaty hands.

OPTION B

Focus card

One big card for the set you're on, with large steppers and one Complete button. Finished sets shrink into chips above.

  • Good: huge tap targets, so it's the easiest to use mid-set.
  • Good: the least to look at, so it feels the most minimal.
  • Weak: you see less of the workout at once, and editing an old set takes an extra tap.

OPTION C

Set grid

Every exercise is one line of set tiles. Tap a tile to complete it at the target; long-press to change the numbers.

  • Good: the whole workout fits on one screen.
  • Good: fastest when you hit your targets: one tap per set.
  • Weak: changing a number is hidden behind a long-press, and there's less room for "previous" numbers.
