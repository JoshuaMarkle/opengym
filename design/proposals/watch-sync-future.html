Watch workouts and calendar

Parked. Kept as a reference for one day: watch workouts shown read-only in History (C1–C3), and planned cardio on the watch through the phone calendar (B). Feasibility for a no-server PWA is in the table below.

C · WATCH WORKOUTS IN HISTORY

Show what you did on the watch

Watch workouts appear in the History calendar as their own read-only entries: an outlined ring next to the blue OpenGym dot. They never edit a logged workout or the plan. The catch is getting them in. A web app can't read Apple Health at all, and Garmin's direct API needs a server and approval. Future feature: automatic sync needs a small server (Strava route) or a native app, so this is parked.

B · WATCH & CALENDAR

Getting cardio onto the watch

Short answer on the PWA question: the calendar route works today for both watches, and finished runs can come back in as files. Pushing real workouts into Garmin or the Apple Watch Workout app can't be done from a web app. B1–B3 are buildable now with no server. B4 and B5 show what the blocked options would look like, flagged in orange.

WANTAS A PWA?WHY
Planned workouts on the watch, as calendar eventsYES, ONE TAPA web app can't write to the phone's calendar by itself. It makes an .ics file and hands it to the share sheet; you tap Add All once. Apple Watch and Garmin both show phone calendar events and alerts. One-way and a snapshot: re-export when the plan changes. A live, auto-updating calendar (webcal subscription) would need the file hosted somewhere, so it's left out.
Watch workouts shown in History (section C)BY FILE AUTO = SERVERManual: parse .fit / .gpx / .tcx on the phone. Automatic: Apple Health has no web API, full stop. Garmin's Activity API needs a server and partner approval (paused). Strava gets workouts from both watches, but its API needs the client secret on a server, and since 2026 the developer needs a Strava subscription. For you alone that's one tiny token function; for other users it breaks "no server".
Push a workout to a Garmin watchNEEDS SERVERGarmin's Training API does this, but it needs a server (OAuth secrets, callbacks) and approval into the Connect Developer Program, which is aimed at businesses and paused new applications in 2026. Breaks "no server" either way.
Push a workout to Apple Watch, read HealthNOThere's no web API for HealthKit or the Workout app. It takes a native iOS app using WorkoutKit plus a $99/yr developer account.
Live heart rate during liftingNOWeb Bluetooth isn't in Safari on iPhone, so even a chest strap can't connect.
