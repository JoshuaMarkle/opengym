RIR badge on the reps box

Four takes on the badge from your screenshot. Each table has the same rows: a warm-up, a done set (2R), the set being edited (1.5R), a set with RIR filled in but not checked yet (set 3), and an empty set (+). The strip under each shows the four states side by side.

Same in every version: the badge's center sits exactly on the bottom-right corner of the reps box (it was a few px high before). Tapping it never changes its size; editing only changes its color or ring. The empty state is always a solid blue circle with a white +, the same size as a one-digit badge.

V1Solid, corrected

Badge sits centered on the box's bottom-right corner. Gray while the set isn't done, faded blue once it's checked, with a 2 px ring in the row's background color so it cuts out cleanly. Editing only turns it full blue; it never grows. Empty stays a blue circle with a white +.
