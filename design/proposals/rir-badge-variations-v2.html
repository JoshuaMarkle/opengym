RIR badge, round 2

Built from V2 (black badge, double border, floating). Done sets take V1's faded blue fill; A and C keep the muted ring, B and D use a full blue ring. The empty + now matches: black, blue ring, blue +. C and D drop the R. Each table has the same rows: a warm-up, a done set (2R), the set being edited (1.5R), a set with RIR filled in but not checked yet (set 3), and an empty set (+). The strip under each shows the four states side by side.

Same in every version: the badge's center sits exactly on the bottom-right corner of the reps box (it was a few px high before). Tapping it never changes its size; editing only changes its color or ring. The empty state is always a solid blue circle with a white +, the same size as a one-digit badge.
