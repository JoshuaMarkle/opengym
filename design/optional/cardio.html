Cardio, kept generic

OpenGym is a lifting app first, so cardio is one flexible exercise type rather than a fitness tracker. Below: three ways to log it, machine presets, interval training, and how it shows up after the workout. Same design system as the complete storyboard.

Cardio sits in the workout like any exercise: time · distance per segment, extras in grey. Intervals collapse to one line. A cardio-only day shows up on the calendar like any other workout.

Suggested scope
• v1: "Cardio" exercise type with time + optional distance and up to two extra fields (B1), presets (B2), logged in the set table (A1). Shows up in Summary and History (D1, D3).
• Later, if wanted: Big fields (A2), interval rounds (C1–C2), Progress → Cardio (D2).
• Probably skip: the in-app timers (A3, C3). Machines already show time, and timers add background-timing complexity on iPhone web apps.
To decide: A1 or A2 as the main cardio view? Distance in mi or km (follows the lbs / kg setting, or separate)?
