S2Side by side: round plates

Bar on the left, total and six round plate buttons (sized like real plates) on the right. Same height as S1. Counts show on the bar itself rather than on the buttons; Undo removes the last plate.

Measured panel heights: A2 ≈ 390 px, S1 ≈ 280 px, S2 ≈ 245 px, number keypad ≈ 245 px. S2 matches the number keypad exactly, so switching between 123 and Plates doesn't make the screen jump; S1 is a little taller but shows counts on the buttons.
B · SUPERSETS

How supersets work, start to finish

Two or three exercises done back to back: a set of one, then a set of the other. Built in the routine, shown as one bracketed group everywhere, and logged on one shared screen.
